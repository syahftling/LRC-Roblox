[ LRC ROBLOX ]

Panduan Penggunaan

Gunakan slash command atau prefix lrc. untuk melihat avatar, profil, presence, grup, role grup, dan item Roblox langsung dari Discord.

Mulai Command Check Avatar Presence Egg Notifier Troubleshooting

Cara menggunakan

Slash command

Ketik tanda /, pilih command milik LRC Roblox, isi parameter, lalu kirim.

/profile username
/presence username
/checkavatarlink username

Prefix command

Ketik prefix lrc. diikuti nama command dan parameter.

lrc.profile username
lrc.presence username
lrc.checkavatarlink username

Check Avatar

Versi Asset ID

Gunakan saat membutuhkan ID item yang sedang dipakai oleh akun Roblox.

/checkavatarid username
lrc.checkavatarid username

Versi tautan

Nama item akan tampil sebagai teks biru yang dapat diklik menuju halaman Roblox.

/checkavatarlink username
lrc.checkavatarlink username

Status Presence

Offline — akun tidak sedang aktif di Roblox.
Online — akun sedang membuka Roblox atau berada di lobby.
Sedang bermain — akun sedang berada di dalam experience.
Roblox Studio — akun sedang menggunakan Roblox Studio.

Notifikasi Steal An Egg

Pengelola server dengan izin Manage Server dapat menjalankan /eggnotify setup, memilih channel notifikasi, channel panel role, dan opsi source_channel sebagai channel privat sumber webhook. Bot akan menyiapkan role kategori dan tombol pilihan.

/eggnotify setup
/eggnotify status
/eggnotify test
Event publik yang dijadwalkan pada Roblox dipantau otomatis. Notifikasi spawn egg aktual dan event yang berjalan dalam siklus game, seperti Butterfly Bloom, membutuhkan sumber data real-time terpisah. Bot tidak mengarang spawn dari timer.

Di Railway, gunakan EGG_DATA_DIR=/app/data dan pasang Volume dengan mount path /app/data agar konfigurasi channel, role, serta riwayat event bertahan saat redeploy.

Contoh penggunaan

/profile Rullzz4SchulloLRC
/presence Rullzz4SchulloLRC
/group 573957203
/grouproles 573957203
/item 104536729705573
/checkavatarid Rullzz4SchulloLRC
/checkavatarlink Rullzz4SchulloLRC

Jika command tidak bekerja

Slash command

Ketik / lalu pilih command dari daftar Discord. Jangan mengirim teks slash command sebagai pesan biasa.

Prefix command

Pastikan prefix ditulis tepat sebagai lrc., kemudian beri spasi sebelum parameter.

Jangan pernah memberikan password Roblox, kode 2FA, cookie .ROBLOSECURITY, atau data login lainnya.
